# 📚 RPA 任务质检通用模态与核心契约参考 (Quality Archetypes Reference)

> **定位**：在为新 RPA 采数脚本定制质检与盲审流水线时，严禁以单一的“显卡售价”标尺衡量全盘业务。本参考手册梳理了四类最典型的 RPA 采数质检模态、其 P0 核心质检指标、致命假数据形态与 L1/L2 防御策略。

---

## 模态一：电商规格与防虚标引流模态 (`SPEC_FRAUD_DEFENSE`)

### 1. 典型业务场景
- 拼多多/淘宝/京东 RTX 5070 Ti 显卡采数
- iPhone 16 / 高端安卓旗舰机采数
- 笔记本电脑、单反相机等高客单价、多复杂 SKU 配置商品

### 2. 核心质检指标 (P0)
- **目标规格真实售价**（如 16G 真实售价 vs 12G 起步价）
- **标题与配置冲突排查**（多规格混写、配件/定金冒充整机）
- **价格统计偏离度**（IQR 箱线图自适应区间）

### 3. 致命假数据形态
- 商家在标题堆砌目标关键词（如 `16G RTX 5070Ti`），但外显标价 `¥7299` 实际是默认选中的低配 `12G 雪狐`；
- 商家以 `¥99 定金/散热风扇` 冒充整卡；
- 手机端采数抓到的是未展开抽屉的外显最低价。

### 4. L1/L2/L3 防御策略
- **L1 (0 Token 规则)**：标题复合冲突正则扫描 + 价格 IQR 箱线图离群度；
- **L2 (真机物理探针)**：真机进入详情页 ➔ 展开 SKU 规格抽屉 ➔ 本地 RapidOCR 识别款式 ➔ 物理点击目标规格卡片 ➔ 监听价格联动跳变并截屏存证 ➔ DeepSeek 确诊；
- **L3 (人机终审)**：一键「按纠偏价¥XXXX通过」或「剔除引流」，修正价格直接同步纯净报表。

## 模态二：榜单排名与品类纯正度模态 (`RANK_HOTNESS_INTEGRITY`)

### 1. 典型业务场景
- 拼多多【品牌罐装啤酒畅销榜 Top 15】采集
- 抖音商品热卖榜 / 实时爆品榜 Top 50
- 微博/小红书行业热搜趋势榜

### 2. 核心质检指标 (P0)
- **榜单排名连续性**（Rank 1..N 连续无断号、无重复、无倒挂）
- **品类准入一票否决**（强品类守护词，苏打水/果汁/饮料绝对拦截）
- **热度指数非空与真实性**（热卖指数、霸榜天数有效，不可为 0 或 NaN）

### 3. 致命假数据形态
- **漏榜/跳号**：页面下滑过快导致第 3 名漏采，序号从 2 直接跳到 4；
- **跨品类漂移**：在啤酒畅销榜中混入了气泡水、下酒花生米、酒具；
- **热度失真**：由于页面懒加载未完成，抓取到的热卖指数显示为空或默认占位符。
- **价格误判**：快消品自然价格跨度大（¥29 ~ ¥120），若按显卡魔数误杀为引流。

### 4. L1/L2/L3 防御策略
- **L1 (0 Token 规则)**：
  - 连号检测：遍历列表校验 `item[i].rank == i + 1`；
  - 品类守卫：必须命中 `category_guard` 关键词（如“啤酒/纯生/精酿/麦汁”），命中黑名单（“苏打水/饮料/下酒菜”）一票否决；
  - 热度断言：`hot_index > 0` 且非空。
- **L2 (真机物理探针)**：
  - **绝不去商品详情页点 16G 显存**！
  - 探针动作：真机拉起对应榜单页 ➔ 滚动到目标排名卡片 ➔ 截取榜单原貌原画 ➔ 验证当前卡片位置与抓取数据是否绝对一致；
- **L3 (人机终审)**：
  - 快捷键「确认在榜」或「剔除跨品类杂质」。

## 模态三：社交互动与内容指标模态 (`SOCIAL_METRIC_MONITOR`)

### 1. 典型业务场景
- B站 UP 主主页及视频数据监控 (`bilibili_video_task`)
- 微信公众号/小红书/快手创作者数据监测
- 直播间实时在线人数与 GMV 遥测

### 2. 核心质检指标 (P0)
- **数值非空与有效性**（播放量、点赞数、投币数、在看人数不可为 0 或 “未知”）
- **互动比率合理性**（点赞率、投币率需在正常阈值内，避免刷量或空壳页）
- **视频元数据匹配度**（UP主名称、视频标题、发布时间完整）

### 3. 致命假数据形态
- 页面未渲染完成即执行 dump，导致播放量提取为“未知”或 0；
- 遭遇滑动验证码或登录拦截弹窗，抓取到了空白占位数据；
- 点赞数大于播放量（数据时序紊乱）。

### 4. L1/L2/L3 防御策略
- **L1 (0 Token 规则)**：
  - 核心字段非空断言（`views > 0`, `title != ''`）；
  - 互动比率校验（如 `likes / views` 处于 0.1% ~ 30% 合理区间）；
- **L2 (真机物理探针)**：
  - 真机重新唤醒 App ➔ 重新定位至目标视频/用户页 ➔ 截图存证 ➔ 重新 Dump 视觉树核验；
- **L3 (人机终审)**：
  - 标记「有效数据」或「页面异常重采」。

## 模态四：系统环境与健康巡检模态 (`SYSTEM_TELEMETRY`)

### 1. 典型业务场景
- 移动端权限巡检与自愈测试 (`sample_mobile_task`)
- 商业 RPA 软件（影刀、实在智能）前台守护
- 手机端后台看门狗与无障碍服务健康探测

### 2. 核心质检指标 (P0)
- **系统状态码与包名存活**（目标 App 是否位于前台）
- **权限与自愈时效**（权限中断是否在 5 秒内自愈）
- **硬件指标安全线**（电池温度 < 45℃、电量 > 20%）

### 3. L1/L2/L3 防御策略
- **L1**：状态码判断（SUCCESS / FAILED）、耗时超时检测；
- **L2**：真机底层 `dumpsys activity` / `dumpsys battery` 原生遥测；
- **L3**：异常推送到飞书/钉钉告警机器人。
